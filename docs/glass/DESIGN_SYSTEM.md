> 지시: "디자인 기반을 유지한 채로 애플 글라스스러운 디자인 개선 시스템을 만들고 그대로 구현. 순서대로 기획, 순차 개발."

## 0. 현황 분석 (P0) — 무엇을 유지하고 무엇을 고치나

개선 전 캡처: `docs/glass/before/*.png` (390×844, 7장)

### 0-1. 반드시 유지할 디자인 기반 (건드리지 않는다)

| 항목 | 현재 값 | 이유 |
|---|---|---|
| 상태색 3종 | 운동 `#E77D75` 코랄 / 휴식 `#648BD2` 블루 / 준비 `#FFE27A` 옐로 | 앱 정체성. 진행 화면 배경과 메인 강조색이 같은 값을 공유하는 원칙 |
| 진행 화면 배경 | 상태색으로 화면 전체 채움 | 멀리서도 상태가 보이는 핵심 기능 (러닝/운동 중 시인성) |
| 서체 | Pretendard, 숫자 tabular | 타이머 숫자가 흔들리지 않음 |
| 정보 위계 | 메인: ①운동/휴식 ②라운드·세트·세트휴식 ③총시간 ④시작 버튼 | 사용자와 확정한 배치 |
| 진행 화면 위계 | 상태 → 링+남은시간 → 라운드/세트 → 진행바 → 조작 | 동일 |
| 기록 화면 | 애플워치식 월 달력 + 링 | 동일 |
| 기능/문구 | 모든 문구, 버튼, 동작 | 디자인 개선 작업이므로 기능 변경 없음 |

### 0-2. 현재 문제 (캡처에서 확인한 사실)

1. **화면마다 재질이 다르다.** 메인만 유리(블러+오브), 설정·기록·완료는 흰색 무광 카드, 진행 화면은 검정 반투명 카드. 앱 하나인데 세 가지 재질이 섞여 있다.
2. **유리 구현이 메인 파일 안에 갇혀 있다.** `_Glass` 가 `ready_screen.dart` 전용 private 클래스라 다른 화면에서 재사용할 수 없다. `AppColors.raised()` 는 이름만 유리이고 실제로는 블러가 없다.
3. **유리 카드 안이 비어 보인다.** 메인 카드 내부에 배경 오브가 뿌옇게 비쳐 "더러운 유리"처럼 보인다. 흰 면이 너무 얇아서(22~46%) 그렇다.
4. **애플식 디테일이 없다.** 모서리가 일반 원호(rounded rect)라 각져 보이고, 가장자리 빛(specular rim)이 한 방향뿐이며, 눌렀을 때 반응이 Material 물결(ripple)이라 애플 느낌과 충돌한다.
5. **진행 화면 조작 버튼이 외곽선 2px 사각형이다.** 상태색 배경 위에서 유리감이 전혀 없다.
6. **완료 화면이 텅 비어 보인다.** 흰 카드 2개와 아이콘 하나뿐이다.
7. **대비 문제:** 완료 화면의 옐로 시간 `13:40` 과 설정 화면의 옐로 `저장`·`8회` 글자는 흰 바탕에서 대비가 약 1.3:1 로 거의 안 읽힌다.

## 1. 디자인 원칙

1. **콘텐츠가 주인공, 유리는 조연.** 숫자(타이머)가 가장 선명하다. 유리는 숫자를 담는 그릇일 뿐 숫자보다 눈에 띄면 안 된다.
2. **재질은 하나의 체계.** 모든 화면이 같은 유리 재질 3단계(§3)만 쓴다. 화면마다 따로 만든 장식은 없다.
3. **빛은 위에서 온다.** 모든 유리 면은 위쪽 가장자리가 밝고(specular), 아래로 부드러운 그림자가 진다. 방향이 통일되어야 입체가 자연스럽다.
4. **색은 상태가 낸다.** 유리 자체는 무채색. 색은 운동·휴식·준비 상태색이 유리에 은은하게 물들어(tint) 나타난다.
5. **읽기 > 예쁨.** 텍스트 대비 4.5:1(작은 글자), 3:1(큰 숫자) 이상. 미달이면 유리를 더 불투명하게 하거나 진한 글자색을 쓴다.
6. **움직임은 짧고 탄력 있게.** 누르면 살짝 작아지고(0.97배) 놓으면 스프링으로 돌아온다. 물결 효과(ripple)는 쓰지 않는다.

## 2. 배경 (GlassBackdrop)

유리는 뒤에 비칠 것이 있어야 유리로 보인다. 화면 종류별 배경을 정한다.

| 종류 | 사용 화면 | 구성 |
|---|---|---|
| `ambient` | 메인, 설정, 기록, 완료 | 밝은 베이스 그라데이션 `#F3F5FC → #FFF4EE` + 상태색 오브 3~5개. 오브는 **크게, 옅게**: 알파 0.35~0.55 (기존 0.5~0.7은 카드 안에서 얼룩으로 보였음) |
| `phase` | 진행 | 상태색 단색 채움은 **유지**. 그 위에 위쪽 밝은 빛(흰색 14%→0) 하나와 아래쪽 같은 색 계열 어두운 빛 하나만 얹어 평면감을 없앤다 |

- 오브 위치는 화면마다 고정된 프리셋을 쓴다. 화면 이동 중 오브가 튀지 않게 한다.
- 완료 화면은 `ambient` 에 운동 코랄과 준비 옐로 오브를 더 크게 넣어 "축하" 느낌을 준다.

## 3. 유리 재질 3단계 (GlassMaterial)

애플 시스템 머티리얼(ultraThin / thin / regular / thick)을 이 앱에 맞게 세 단계로 줄였다.

| 단계 | 용도 | 블러 σ | 면 채움(밝은 배경) | 면 채움(상태색 배경) | 테두리 rim |
|---|---|---|---|---|---|
| `thin` | 칩, 작은 알약, 보조 정보 | 18 | 흰색 38% | 흰색 16% | 흰색 55% → 15% |
| `regular` | 카드 기본 (메인 카드, 설정 행, 기록 카드) | 24 | 흰색 58% | 흰색 20% | 흰색 85% → 25% |
| `thick` | 시트, 다이얼로그, 상단 바, 가독성이 최우선인 곳 | 32 | 흰색 78% | 흰색 28% | 흰색 90% → 30% |

모든 단계 공통 구성 (아래에서 위로 쌓는 순서):

1. **그림자 2겹**: 넓고 옅은 바닥 그림자(blur 30, y+14, 잉크 10%) + 가까운 접지 그림자(blur 3, y+1, 잉크 5%)
2. **배경 블러** (BackdropFilter)
3. **면 채움**: 위쪽이 아주 조금 더 밝은 세로 그라데이션
4. **틴트**(선택): 상태색 8~14%
5. **위쪽 하이라이트**: 위 0~45% 구간 흰색 35%→0
6. **테두리 rim**: 위가 밝고 아래가 옅어지는 그라데이션 테두리 1px. 애플 유리 가장자리의 반짝임을 만드는 핵심 요소
7. 콘텐츠

## 4. 형태 토큰

### 4-1. 곡률: 연속 곡률 모서리(squircle)
애플 UI 모서리는 원호가 아니라 연속 곡률이다. Flutter 3.35의 `RoundedSuperellipseBorder` / `ClipRSuperellipse` 를 쓴다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `r.xs` | 10 | 칩, 작은 배지 |
| `r.sm` | 14 | 설정 행, 작은 버튼 |
| `r.md` | 20 | 카드 기본 |
| `r.lg` | 26 | 큰 카드 (메인 운동/휴식, 달력) |
| `r.xl` | 32 | 바텀시트 상단 |
| `r.pill` | 999 | 알약 버튼, 칩 |

### 4-2. 간격 (4pt 그리드)
`4 · 8 · 12 · 16 · 20 · 24 · 32`. 화면 좌우 여백 18, 카드 사이 12, 카드 안쪽 16.

### 4-3. 타이포 (Pretendard 유지, 위계만 정리)

| 토큰 | 크기/굵기 | 용도 |
|---|---|---|
| `display` | 46~260 / w900, 자간 -1.8 | 타이머 숫자 (화면별 크기 유지) |
| `title` | 17 / w800 | 화면 제목 |
| `headline` | 15 / w800 | 카드 제목 |
| `body` | 14 / w700 | 행 라벨 |
| `caption` | 11.5 / w600~700 | 보조 설명 |
| `overline` | 11.5 / w800, 자간 1.1 | 섹션 라벨 |

### 4-4. 글자색 (밝은 유리 위)
- 주: `#15161B` / 보조: `#5B5F6E` / 3차: `#747886`
- **진한 상태색**(글자 전용, 흰 유리 위 대비 확보): 운동 `#AD3F38`, 휴식 `#2F5DAA`, 준비 `#7A5C00` (대비 테스트로 확정)
- 옐로를 글자로 쓰던 곳(완료 시간, 설정 `저장`, 라운드 값)은 모두 진한 준비색 `#7A5C00` 또는 잉크로 바꾼다. 원래 옐로는 면·점·링 색으로만 쓴다.

## 5. 모션

| 토큰 | 값 | 용도 |
|---|---|---|
| `press` | scale 0.97, 90ms easeOut | 누를 때 |
| `release` | spring (stiffness 400, damping 26) | 놓을 때 |
| `state` | 220ms easeOutCubic | 선택 상태, 토글 전환 |
| `phase` | 360ms easeInOut | 진행 화면 배경색 전환(운동↔휴식) |

- 물결 효과(InkRipple)는 끈다 (`splashFactory: NoSplash`).
- 진행 화면 배경 전환은 `AnimatedContainer` 로 부드럽게 바꾼다. 타이머 계산에는 영향을 주지 않는다(표시만).

## 8. 검증 기준

공통 (매 단계):
- `flutter analyze` 이슈 0
- 기존 테스트 전부 통과 (기능 회귀 없음, 문구 변경 없음)
- 캡처로 확인: 재질 3단계 외 다른 재질 없음, 위쪽 rim 하이라이트 보임, 모서리 squircle

정량 기준:
- 텍스트 대비: 작은 글자 ≥ 4.5:1, 큰 숫자(24pt 이상) ≥ 3:1. 유리 면을 배경 위에 합성한 실제 색으로 계산한다 (`test/glass_contrast_test.dart`)
- 진행 화면: 상태색 배경 값이 `AppColors.workBg / restBg / prepareBg` 와 동일 (정체성 유지)
- 터치 영역 ≥ 44×44
- 성능: BackdropFilter 는 화면당 카드 수만큼만 쓰고, 진행 화면에서 매 프레임 바뀌는 숫자 영역에는 블러를 겹치지 않는다 (링·숫자는 유리 밖)
